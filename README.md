One pickup line, 200 characters at most, as if a vending machine were
flirting with a passing human — for the
[One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee).

`main.py` (stdlib only, no network) writes the line to
`$ENTRY_OUTPUT_DIR/entry.txt`. Run it with:

```sh
ENTRY_OUTPUT_DIR=/tmp/out python3 main.py
```
